# Перевірки збірки VibeBench

04.10.2026 виконано дві чисті Docker-збірки на Mac і одну чисту збірку в Ubuntu 24.04.5. У кожному запуску спочатку виконано make clean, потім make build. Усі команди завершилися з кодом 0. Час у логах є фактичним UTC, для місцевого часу додати 3 години. Дати Git-комітів не є часом запуску перевірок.

| Запуск | Архітектура контейнера | Docker | ARM GCC | Доказ |
|---|---|---|---|---|
| Mac 1 | arm64 | 29.6.1 | 10.3.1, пакет 15:10.3-2021.07-4 | [лог](macos-1.log), [SHA256](macos-1.sha256) |
| Mac 2 | arm64 | 29.6.1 | 10.3.1, пакет 15:10.3-2021.07-4 | [лог](macos-2.log), [SHA256](macos-2.sha256) |
| Ubuntu 1 | amd64 | 29.1.3 | 10.3.1, пакет 15:10.3-2021.07-4 | [лог](ubuntu-1.log), [SHA256](ubuntu-1.sha256) |

Dockerfile збережений із шаблону. Він задає базу й пакети, але не фіксує digest базового образу або версії apt-пакетів. IDs фактично використаних образів записані в логах. Ці результати підтверджують повторюваність виконаних запусків, а не будь-якої майбутньої збірки після оновлення пакетів.

## Розбір відмінності ELF

[Фактичне порівняння](elf-comparison.log) перевіряє секції ELF32, вивід arm-none-eabi-readelf та тимчасові копії після arm-none-eabi-objcopy --strip-debug. Серед секцій відрізняється лише .debug_str. readelf показав DW_AT_comp_dir із різними шляхами збірки пакетного libgcc для arm64 і amd64. Це дані вже зібраної бібліотеки toolchain, а не шлях проєкту.

Усі секції з прапором ALLOC збігаються. Тимчасові stripped ELF мають однаковий SHA256 `a3e7c7f6f75dad9b378868472978f3557b3f3ae74a45a7e1d531e48d711859de`. Оригінальні ELF не очищалися й не замінювалися. Для побайтного збігу оригінального ELF між середовищами в майбутньому треба використовувати однакову архітектуру й зафіксований образ toolchain.

## Що ще не підтверджено

Симуляцію Wokwi не запускали. ready, tick та LED описані за кодом і ще потребують реального спостереження. Датчики, вікна вимірювання й тести ЛР2 не реалізовані. Логи компілятора не є UART-логами. Фізична плата, електричні сигнали та точність акселерометра не перевірялися.

Артефакти залишаються локально у firmware/build і виключені з Git. PDF-звіт і відео ще потрібно додати окремо після демонстрації.
